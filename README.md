
# Mini Gestor de Tareas

Aplicación web sencilla para organizar tareas diarias.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Agregar tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Contabilizar tareas pendientes y completadas.

## Ejecución
Abrir el archivo index.html en un navegador.
